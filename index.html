MiChelly — personal HBC repository

Custom Homebrew Channel repository for MiChelly, a personal fork of jellyfin/jellyfin-webos (com.daverui.michelly, version 1.3.1). It is a webOS client that connects to a Jellyfin server and opens its web UI.

Add this URL as a repository source in Homebrew Channel:

https://daver-ui.github.io/webos-hub/repo.json

Artifacts

  • repo.json — the repository document
  • com.daverui.michelly_1.3.1_all.ipk
  • icons/michelly.png

The IPK is verified by Homebrew Channel against the ipkHash.sha256 in repo.json.

Because the app id changed, the TV will list MiChelly as a new app, separate from the official Jellyfin client.
